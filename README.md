# 1.  Бизнес-анализ (Business Understanding)

---

### Бизнес-цель

Создать модель автоматической классификации стадий диабетической ретинопатии по цветной фотографии глазного дна, пригодную для использования в системах поддержки врачебных решений при массовом скрининге

**Почему это важно:**
- Диабетическая ретинопатия (далее ДР) — ведущая причина предотвратимой слепоты среди трудоспособного населения
- Скрининг вручную занимает 15–20 минут на снимок и требует узкоспециализированного врача
- Автоматизация позволяет охватить пациентов с диабетом в регионах с дефицитом офтальмологов

**Ожидаемый эффект:**
- Сокращение времени анализа одного снимка с 15 минут до < 5 секунд
- Более раннее выявление прогрессирующих стадий
- Уменьшение числа запущенных случаев из-за несвоевременной диагностики

### Существующие решения

На сегодняшний день существует несколько FDA-одобренных AI-систем: LumineticsCore (2018), EyeArt (2020/2023), AEYE-DS (2024). Все они решают задачу бинарной классификации (реферабельная / не реферабельная ДР) для массового скрининга.

Однако академические исследования показывают принципиальную возможность 5-классовой классификации, более близкой к реальной врачебной практике.

Цель проекта — воспроизвести и независимо проверить результаты академических исследований (включая работу [Dash et al., 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC9406859/)) с использованием открытых датасетов APTOS 2019 и IDRiD, а также оценить возможность использования подобных моделей в коммерческом контексте.

## 1.2 Решаемые задачи с точки зрения аналитики (Data Mining Goals)

- **Тип задачи:** Многоклассовая классификация
- **Вход (Input):** RGB-изображение глазного дна
- **Выход (Target):** Один из 5 классов: 0 — No DR, 1 — Mild, 2 — Moderate, 3 — Severe, 4 — Proliferative DR

| Класс | Название | Описание |
|-------|----------|----------|
| 0 | No DR | Нет признаков ретинопатии |
| 1 | Mild | Единичные микроаневризмы |
| 2 | Moderate | Умеренные изменения, не достигающие критериев тяжёлой стадии |
| 3 | Severe | Обширные кровоизлияния, венозные изменения, новые сосуды отсутствуют |
| 4 | Proliferative DR | Неоваскуляризация, высокий риск слепоты |

| Датасет | Назначение | Объём |
|---------|-----------|-------|
| [APTOS 2019](https://www.kaggle.com/competitions/aptos2019-blindness-detection/data) | Обучение + валидация | ~3 662 изображения |
| [IDRiD](https://ieee-dataport.org/open-access/indian-diabetic-retinopathy-image-dataset-idrid) | Тест (независимый) | 516 изображений (Disease Grading subset) |

### Метрики

| Метрика                            | Связь с бизнес-целью | Минимальное значение | Целевое значение |
|------------------------------------|----------------------|----------------------|------------------|
| **Quadratic Weighted Kappa (QWK)** | Точность определения стадии; квадратично штрафует за грубые ошибки (например, когда тяжёлую стадию ошибочно классифицируют как здоровую или лёгкую) | ≥ 0.80               | ≥ 0.90           |
| **Macro-averaged Recall**          | Полнота обнаружения каждой стадии в отдельности; гарантирует, что модель одинаково хорошо выявляет и редкие клинически значимые классы (Mild, Severe, Proliferative) | ≥ 0.70               | ≥ 0.75           |
